## 1. 方針

「朝焼けインク（Dawn Ink）」。淡い紙色の地に、濃いインク色の文字と線を置き、朝の光はコーラルと赤だけに使う。ナビは4つに組み直し、ホームは「次の起床」を主役にした別のレイアウトにする。アラームの挙動・保存データ・設定値・スケジューラは変えない。

## 4. 形・文字・余白・動き

- 角丸: ヒーロー 28dp、カード 20dp、入力欄 14dp。ボタン・チップ・FAB はピル（全円）。
- 影は原則なし（紙の質感）。FAB と下部の保存バーの上端だけ elevation 4dp。
- 線は 1dp の LINE。フォーカスは 2dp の INK。
- 余白は 4dp の倍数。画面の左右 20dp（幅 360dp 未満は 16dp）。セクション間 24dp。カードの中 16dp。
- 当たり判定は最小 48dp（見た目が小さくても当たりは 48dp）。
- 文字（sp）: 次の起床の時刻は sans-serif-light・tnum・76（autoSize で最小 60%、1行）。一覧の時刻は sans-serif-medium・tnum・30。画面題名は sans-serif-medium・28。見出しは 14（INK_2）。本文は 16。補助は 13（ナビのラベルだけ 12）。
- 寸法は dp、文字は sp。高さを固定せず minHeight を使う（文字拡大に備える）。
- ダークモードは作らない（従来どおり非対応。明るい色だけ）。
- 動き: 画面切替は 0〜120ms。スイッチは 120ms。跳ねる動きはなし。
- 独自性は3点: (1) 次の起床の時刻の区切りを「点2つ」にする（ヒーローだけ）。(2) 24時間の地平線に、起床の位置を朝日の点で示す。(3) コーラルの朝焼けの面と、INK と RED の行動色。

## 6. 画面の設計

### 6.1 アラーム（ホーム）

```
[ヒーロー・CORAL の面]
  次の起床                          [平日]
    06 o 30                 76sp。区切りは点2つ
    平日の朝   [計算 x3]
    あと 7時間 12分
    ---o----------------------------  24時間の地平線
[一覧・CARD]
  アラーム                        有効 3 / 全 5
  06:30  平日      朝の運動              (on)
         月火水木金  [歩数 10]
  08:00  一回だけ   会議前              (off)
         [起きた] [取消]   ※スヌーズ中の行だけ
[FAB・RED]                    ( + アラームを追加 )
[ナビ]  アラーム | 時計 | 記録 | 設定
```

要点:
- アプリバー: 左に小さな Ignido マーク（ic_ignido_v299_foreground）と「WakeGuard」。右に「連続 N日」のチップ（記録へ）。歯車は置かない（設定はナビへ）。
- 次の起床のヒーロー: CORAL から CORAL_2 への斜めのグラデーション。角丸 28dp、余白 20dp、文字は INK。
  - 上段: 「次の起床」（14）と、繰り返しの文字のチップ（平日・一回だけ・毎日など、既存の文字）。
  - 時刻: 76sp。区切りは INK の丸2つ（7dp）。ヒーローの中だけ「:」を使わない。
  - 下段: ラベル（16）と、ミッションのチップ（例: 計算 ×3）。「あと 7時間 12分」（既存の relativeText）。
  - 24時間の地平線: 高さ 6dp。地は INK の 15%。起床の位置に朝日の点（INK、10dp）。現在時刻に縦線（INK）。
  - 読み上げ: ヒーロー全体で1文（例:「次の起床 06時30分、あと7時間12分」）。
  - タップで、その次のアラームを編集で開く。
  - 次の時刻の計算（refreshNext。nextTriggerMillis と SnoozeScheduler.nextAt の早い方）は変えない。表示だけ変える。
- 一覧: 1枚の CARD（角丸 20dp、縁 LINE）。行は最小 72dp。左に時刻 30sp（medium・tnum）と繰り返しの文字（13・INK_3）。中央にラベル（16・1行で省略）、ミッションのチップ（CORAL_SOFT）、残り時間（INK_2）。右に有効スイッチ（48dp）。行の間は LINE の 1dp。
  - 無効の行: 時刻とラベルを INK_3 に。スイッチは残す。
  - スヌーズ中の行: 地を CORAL_SOFT に。残り時間の下に「起きた」「取消」（既存の動作と表示条件のまま）。
  - 行をタップで編集。長押しで削除（追加アラームだけ・確認あり・既存どおり）。
- 追加: 右下に RED のピル型ボタン「＋ アラームを追加」（56dp）。ナビの上に 16dp。上部の＋は置かない（重複を避ける）。
- 0件: ヒーローに「アラームはまだありません」と INK のボタン「アラームを追加」。一覧は出さない。
- 既存の警告表示（あれば）は同じ文言で残す。現行の表示は実装者が確認する。

### 6.2 アラーム編集（追加・編集）

```
[←] アラームを編集
[A 時刻・曜日・有効 / CARD]
  06 : 30                              有効 (on)
  (月)(火)(水)(木)(金)(土)(日)
  曜日なし = 一回だけ（説明）
[B 名前]        平日の朝
[C 解除ミッション]
  計算    回数 (-) 3 (+)                    [変更]
  （変更で開く選択パネル: 体を動かす / 頭を使う / おまかせ・なし の2列タイル）
[D 通知]        事前通知 30分前 >
[E スヌーズ]    (on)   再通知まで 5分 >     このアラームだけ
[F サウンド]    標準音  [試聴] [選択] [標準に戻す]   音量 ---o--- 15
[G 振動]        ( ) オフ  (o) 不規則  ( ) 強い連続パルス
[H 自動停止]
  音と振動を止める      (on)   鳴り始めから  止めるまで >
  アラーム全体を終える  (off)
[I]  [このアラームをテスト]   [アラームを削除]（追加アラームのみ）
[下部に固定]  [ 保存 ]   INK・全幅
```

要点:
- 上部: ← と題名（22sp）だけ。歯車は置かない。
- A「時刻・曜日・有効」カード: 時刻を大きく（タップで既存の時刻ピッカー。変更で fixedAt を 0 にする既存の動作のまま）。右上に有効スイッチ。月〜日は7つのチップ（押すと on/off。並びは 月 火 水 木 金 土 日 のまま）。曜日が1つもないときは「曜日なし＝一回だけ」の説明を出す。
- B「名前」: 入力欄（14dp、縁 LINE）。既定値は既存どおり（新規は「アラーム」、主は「メインアラーム」）。
- C「解除ミッション」: 選択中の要約カード（ミッション名、説明、回数の −/+）と「変更」。「変更」で同じ画面の選択パネルを開く。
  - 選択パネル: 3つのグループ（体を動かす／頭を使う／おまかせ・なし）と、2列のタイル（最小 64dp）。タップで即決定してパネルを閉じる（OK ボタンなし＝現状どおり）。
  - グループ（表示だけ。保存は key で行う）: 体を動かす＝STEPS、SHAKE、TAP、HOLD、SWIPE ／ 頭を使う＝MATH、MEMORY、ORDER、REVERSE、TYPE、CODE ／ おまかせ・なし＝RANDOM、NONE。
  - 回数: −/+ の丸ボタンと数字。内部の値は既存の回数欄と同じ（1〜500、空は 3）。歩数は STEPS と RANDOM だけ（1〜9999、空は 10）。ラベルは既存どおりミッションごとに変える。
  - タイルの説明文は、実装者が buildMission の実際の操作を読んで書く（推測で書かない）。
- D「通知」: 事前通知（既存の選択肢。オフ・5・10・15・30・60・120・カスタム 1〜1440、既定 30）。説明は「鳴る前にお知らせします」。
- E「スヌーズ」: スイッチ（ON にすると既定は 5 分）と「再通知まで」（1・3・5・10・15・20・30・45・60 分）。説明は「このアラームだけに使います」。
- F「サウンド」: 今の音の名前、試聴、選択（音声・動画）、標準に戻す。音量 0〜100（既定 15）。
- G「振動」: 3択（オフ・不規則・強い連続パルス。既定は不規則）。縦の選択行。
- H「自動停止」: 2つの小さなカード。
  - 「音と振動を止める」（ringDurationSec）: スイッチと時間（鳴り始めから。0 は「止めるまで」）。説明は「止まっても、ミッションの画面は残ります」。
  - 「アラーム全体を終える」（fullStopDurationSec）: スイッチと時間（鳴り始めから。0 は「止めるまで」）。説明は「終わると、アラームは全部止まります」。
  - 両方あり、全体が音と振動以下のときは既存の警告文を出す。上限は 86400 秒（既存）。
- I: 「このアラームをテスト」（INK の縁のボタン。既存どおり保存して再予約してから試し鳴らし。確認なし）と「アラームを削除」（追加アラームだけ・RED の文字・既存の確認あり）。
- 下部に固定: 「保存」（INK、全幅、高さ 56dp）。既存の保存（検証、失敗時のトースト、成功で閉じる）をそのまま使う。

要点:

## 7. 文言（I18n）

## 8. 変えてはいけないもの（保持リスト）

1. ミッション13種: NONE、STEPS、MATH、TAP、CODE、SHAKE、MEMORY、TYPE、HOLD、SWIPE、ORDER、REVERSE、RANDOM（AlarmEditorActivity.java:21-22）。保存は key で行い、グループ分けは表示だけ。RANDOM の抽選は 11 種（NONE と RANDOM を除く。AlarmProfiles.java:66）。
2. 曜日: days の bit0 は月。並びを変えない。曜日なし＝一回設定（AlarmStore.java:29）。
3. fixedAt: 0 は「未設定」の番兵。時刻を変えると 0（AlarmEditorActivity.java:43）。しきい値（+1 秒と +2 秒の食い違い）は触らない。
4. 主アラーム（id=1、保存先は wake_guard）と追加アラーム（id≥1000、保存先は wake_guard_multi_alarms）。主は削除できない。
5. 個別スヌーズ: snoozeMinutes は 0〜60（0 はオフ）。新規の既定は 0、欠損時は 5（AlarmStore.java:47）。
6. 2系統の自動停止（AlarmService.java:324-357）: ringDurationSec は、セッション開始（鳴り始め）から経過すると音と振動だけ止まり、ミッション画面は残る。fullStopDurationSec は、経過するとアラーム全体が終わる。0 は「止めるまで」。両方あるときは全体が先に働く（警告を残す）。
7. 起床記録（StreakTracker、WakeStats）: テストは記録しない。成功は総起床回数。
8. 保存の検証: 歩数 1〜9999（空は 10）、回数 1〜500（空は 3）、失敗時のトースト「設定値を確認してください」、削除の確認、戻るは保存しない。
9. SharedPreferences の名前と JSON のキー（id、hour、minute、days、enabled、label、steps、missionType、missionCount、volume、vibration、soundUri、soundName、soundBytes、soundDurationMs、fixedAt、ringDurationSec、fullStopDurationSec、preNotifyMin、snoozeMinutes）は変えない（AlarmStore.java:55-59）。
10. ランチャーアイコン（ic_launcher、ic_ignido_approved_*、背景 #010B3C）は触らない。
11. 依存は増やさない（Material や AppCompat は入れない）。Activity も増やさない（ミッション選択は画面内のパネル）。
